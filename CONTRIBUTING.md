# Contributing to ChainVolio

Thank you for your interest in contributing to ChainVolio.

## How to Contribute

1. **Report bugs** — Open an issue with the "bug" label. Include steps to reproduce,
   expected behavior, actual behavior, and browser/wallet version.
2. **Suggest features** — Open an issue with the "enhancement" label.
3. **Submit a PR** — Fork the repo, create a branch, and submit a pull request.
   Keep PRs focused — one feature or fix per PR.

## Development Setup

See the [README](README.md) for local development instructions.

## Commit Convention

We use conventional commits: `feat:`, `fix:`, `chore:`, `refactor:`, `perf:`, `docs:`

## Security Issues

Do not open a public issue for security vulnerabilities.
See [SECURITY.md](SECURITY.md) for responsible disclosure guidelines.
